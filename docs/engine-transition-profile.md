# 탐색의 엔진 전이 시간 비중 재측정

## 방법

[최근 직접 누적 비교](<engine-cumulative-optimization.md>)의 원본 탐색 기록에 포함된 타이밍 카운터를 분해했다. 별도 benchmark를 다시 실행하거나 소스를 수정하지 않았다. 최초 최적화 전 release와 구조 최적화 최종 release, 직렬 AB/BA, seeds 1/2/3 각각 3회, chance_samples=4/search_seed=19다. 각 조건은 8개 국면 × 9회 = 72개, 카드 진행 국면은 4개 × 9회 = 36개다.

전이 비중은 `stats.apply_ms / report.elapsed_ms`이며 프로세스 시작·규칙 로딩 시간은 분모에 포함하지 않는다. 합계 비중은 비율의 단순 평균이 아니라 `sum(apply_ms) / sum(elapsed_ms)`다. `apply_ms`는 엔진 호출 경계의 wall-clock이며 내부 검증·상태 복사·이벤트·확률 처리를 포함한다. 내부 함수별 CPU 샘플링 결과는 아니다.

[원래 감사](<model-free-baseline-audit.md#L116-L139>)의 91.7–96.0%는 250ms 카드 진행 국면의 관측 범위였다. 아래는 같은 조건을 반복한 최근 측정치다.

## 250ms 카드 진행 국면

| 항목 | 최초 | 최종 |
|---|---:|---:|
| 36개 탐색의 전이 비중 합계 | 94.16% | **82.40%** |
| 개별 탐색 전이 비중 범위 | 91.34–96.04% | **75.69–88.51%** |
| 합법 행동 생성 비중 합계 | 3.52% | 9.94% |
| 정적 평가 비중 합계 | 0.23% | 0.75% |
| 기타 탐색·계측 잔차 | 2.08% | 6.91% |

전이 비중은 **11.77%p 감소**했다. 최대 깊이 4까지 더 빨리 완료하거나 더 많은 노드를 방문하므로 양쪽 작업량은 같지 않다.

국면별 값은 각 9회에서 계산한 비중의 중앙값이다.

| 카드 진행 | 최초 전이 비중 | 최종 전이 비중 |
|---|---:|---:|
| decision 4 | 92.73% | 81.73% |
| decision 8 | 94.44% | 77.19% |
| decision 16 | 95.90% | 80.75% |
| decision 24 | 95.46% | 85.55% |

## 같은 작업량: depth 3 고정 탐색

72개 탐색에서 행동·점수·완료 깊이·노드·전이 호출 등은 모두 일치했다. 전이 호출은 양쪽 **130653회**다.

| 항목 | 최초 | 최종 |
|---|---:|---:|
| 총 탐색 시간 | 4779.92ms | 1254.07ms |
| 엔진 전이 시간 | 4549.97ms | 1071.59ms |
| 전이 비중 | 95.19% | 85.45% |
| 전이 호출당 평균 | 34.82µs | 8.20µs |
| 합법 행동 생성 | 114.21ms / 2.39% | 73.92ms / 5.89% |
| 정적 평가 | 11.40ms / 0.24% | 11.03ms / 0.88% |
| 기타 잔차 | 104.33ms / 2.18% | 97.54ms / 7.78% |

전이 자체는 **4.25배 빨라졌고 76.45% 시간이 감소**했다. 비중보다 절대 시간이 더 크게 줄었다. 합법 생성도 절대 시간은 줄었지만 총시간이 더 크게 줄어 상대 비중은 증가했다. 정적 평가 비용은 거의 같으며 GPU/신경망 추론이 아니다.

## 해석

- 전이 병목은 크게 완화됐지만 여전히 가장 크다. 250ms 카드 국면에서는 전이+노드별 합법 생성이 합쳐서 **92.34%**다. 고정 작업 전체에서는 **91.34%**다. 따라서 엔진 전체가 탐색의 주된 비용인 상황은 유지된다.
- 전이 내부의 상태 복사·이벤트·공격 판정 각각의 비율은 아직 이 카운터로 분리할 수 없다. 다음 병목 판단에는 별도 세부 계측이 필요하다.
- 노드별 합법 생성은 전이 호출 밖에서 별도로 측정된다. 과거 전이 내부의 중복 생성 비용은 apply_ms에 포함되어 있어, legal_ms만으로 모든 합법성 검사의 비용을 표현하지 않는다.
- 이 결과는 모델 없는 알파베타 기준선이며 ONNX MCTS의 동일 비중이나 기력 개선을 입증하지 않는다.
