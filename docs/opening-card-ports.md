무작위 오프닝 대상이 하나이면 추첨하지 않는다. 새 종류로 바뀐 기물과 소환 기물의 포획 지연은
원본의 오프닝 예외에 따라 구분한다. 존버 기한과 수배 상태는 탐색 상태와 반복 키에 포함한다.
친정과 도적의 선택 추가 이동에는 `SkipOptionalMove` 행동을 추가했고 웹에서도 건너뛰기 버튼을 표시한다.
퀸즈 갬빗과 기존 보호의 중첩 및 이후 임시 보호의 만료를 추적하며, 상인 매수 시 보호의 출처를 구분한다.
강림의 착지점 선택과 실제 귀환, 거짓 출발과 예약 소환에도 d4 제한을 적용한다.

`scripts/test-opening-acquisition.mjs`는 고정된 원본의 오프닝 선택·배치 헬퍼와 d4 제한을 검사한다.
`engine/cards/tests/opening_cards.rs`는 양 진영의 배치·변환, 특수 룰 좌표, ID·상태 보존,
예약 승진, 추첨, 후속 제거, 수배 체포, 추가 이동 건너뛰기와 상인의 매수를 검사한다.

지원은 위에서 구현한 계약과 검증 범위를 뜻한다. 여러 칸을 동시에 공격하는 효과와 대형 기물의 조합,
d4와 아직 이식하지 않은 모든 강제 배치의 조합, 여러 카드의 동시 포획 정산 및 원본 난수 예약의
전체 일치 검증은 남아 있다.
