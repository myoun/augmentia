# 최신 룰셋 카드 이식 현황

2026-11-07, 중반 4장과 후반 30장 이식 완료 기준. 대상은 `augment_chess_20261017`의 최신 실행 프로필이다.

275장 중 **271장을 지원**하고, 남은 4장은 모두 **원본 비활성**이다. 활성 이식 대상은 0장이다.
비활성 4장은 실행 지원 목표에 포함하지 않는다.

이 룰셋은 2026-10-17 발표를 기준으로 2026-10-28 live 번들을 수집한 것이다.
10-17 당시 바이트를 검증했다는 뜻은 아니다. 카드 설명은 보관된 canonical 카탈로그에서 가져왔다.

## 목록의 근거와 읽는 법

- [최신 카탈로그](../rulesets/augment_chess_20261017/cards/catalog.json): 이름·분류·효과 설명·활성화·턴 정책.
- [최신 실행 프로필](../rulesets/augment_chess_20261017/cards/implemented.json): `cards` 271장의 실행 계약과 `pending` 4개의 미지원 사유.
- [이식 기록](../rulesets/augment_chess_20261017/cards/ported.json): 카드별 원본 위치·범위·남은 차이.
- [0915 대비 차이](../rulesets/augment_chess_20261017/sources/0915-delta.json): 변경 필드와 이전/이후 정의.
- [원본 수집 근거](../rulesets/augment_chess_20261017/sources/source-manifest.json): 번들 URL·digest·수집 시각.
- [카드 구현 안내](card-implementation.md): 카드 파일·등록부·공통 처리·과거 정의와 테스트 위치.
- [후속 조사 항목](remaining-card-ports-followup.md): 이식 후 남은 확인 과제.

`변경`은 `changed_contract_not_ported`, `신규`는 `new_card_not_ported`,
`원본 비활성`은 `disabled_upstream`에 대응한다. 변경 필드 표시는 자동 비교 기록이며
실제 동작 차이의 전수 조사 결과는 아니다.

RULE은 canonical 데이터의 `activation` 값과 별개로 엔진에서 규칙 설치로 처리한다.
같은 이름도 ID가 다르면 별도 카드다. 예: RULE 실수와 중반 실수, 두 종류의 컨베이어.

## 후반 이식 완료 32장

전체 32장을 `96b3769`에서 완료했다. 카드별 원본 위치·범위·남은 차이는
[이식 기록](../rulesets/augment_chess_20261017/cards/ported.json)에 있다.

이식 중 **기존 배선의 계약 위반 3건**을 발견해 교체했다.

- `icbm`: 기존 정산이 추적한 퀸 ID를 무시하고 아무 상대 퀸이나 폭발시켰으며, 원본 퀸을 희생하지도 않았다. 퀸 정체성을 추적해 희생·3×3 폭발·보호·왕실 순서를 맞췄다.
- `gale`: 최신 카탈로그에서 END로 분류가 바뀌었는데도 0915 중반 규칙("주변에 아군이 없는")으로 돌았다. 메이저 기물끼리의 격리 판정으로 교체했다.
- `vanish`: 한쪽만 제거했다. 양측 각 1개, 첫 공유 턴 왕 제외, 65/100 가중치로 교체했다.

이후 `5c8d9ed`에서 다음 두 가지를 추가로 고쳤다.

- HP 피해로 대형 기물을 격파한 경우와 통나무 굴림으로 포획한 경우가 `PieceCaptured`를 발행하면서도 `capture_count`를 올리지 않아, 그 기물이 `judgment` 후보에서 빠졌다. 원본은 모든 포획을 집계한다.
- `black-magic`의 아군 괴물이 엔진의 괴물 이동 차단 때문에 움직이지 못했다. 아군 괴물을 별도로 추적해 3반수마다 퀸 1칸 이동·일반 적 포획을 하도록 연결했고, 중립 괴물은 그대로 두었다.

`d9d3f01`에서는 `collapse` 카드와 `periodic-collapse` RULE이 같은 턴 경계에
함께 정산돼 링을 두 번 제거하던 문제를 고쳤다. 원본은 같은 경계에서 카드 붕괴가
이미 처리됐으면 주기 정산을 건너뛴다.

## 범위 갱신

이 문서는 미지원 ID 목록이 아니라 **이식 현황**이다. 이미 지원 중인 271장의 전체
상호작용·원본 동작 일치 검증은 별도의 남은 작업이며 이 4장 수량에 더하지 않는다.
상세한 후속 조사 항목은 [후속 조사 항목](remaining-card-ports-followup.md)에 있다.

지원 목록이 바뀌면 `pending`과 표의 ID 집합이 정확히 같은지 확인하고,
`지원 + 미지원 = 275`, `변경 + 신규 + 비활성 = 미지원`을 함께 검증한다.
`scripts/test-latest-ruleset.mjs`가 `profile.pending.length`와
`implemented.cards.length`를 카탈로그와 대조하므로 수량 불일치는 테스트에서 잡힌다.
