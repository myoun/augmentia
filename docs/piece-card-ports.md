## 원본과 대상 선택

보관한 `rulesets/augment_chess_20261017/sources/raw/main-RjrZ5fFP.js`의 실행 계약을 기준으로 했다.
SHA-256은 `2e932da7b9391effbeab3593ea5fdf855041fe5a74f611dfdfde678eee46beb8`이다.
2026-10-17 발표를 기준으로 10-28에 수집한 바이트이며 발표 당일 바이트의 증명은 아니다.
원본 줄 범위와 카드별 범위는 [ported.json](../rulesets/augment_chess_20261017/cards/ported.json)에 있다.

18장 모두 사용 후 턴을 유지한다. 아래의 마이너는 최신 원본의 기물 종류 분류이며 중립 설치물을 포함하지 않는다.
비왕실 조건은 일반 킹뿐 아니라 편집 국면에서 왕실로 지정한 기물도 제외한다.
원본 선택 헬퍼가 편집 왕실을 허용하는 카드에는 일괄적인 왕실 금지 조건을 덧붙이지 않았다.

## 상태와 턴 경계

변환은 기물 ID·포획 횟수·일반 상태를 보존하고 이전 종류의 전용 상태를 정리한다.
실제 종류가 바뀔 때 퀸즈 갬빗 연결 보호를 해제하고 새 종류 상태를 초기화한다.
대부분의 변환은 이동한 기물로 표시하며 풍차 한 쌍은 기존 이동 여부를 유지한다.
같은 종류로 다시 바꾸면 카드 사용은 처리하되 새 포획 지연을 다시 만들지 않는다.

새 변환·배치 기물은 완료한 반수 두 번 뒤부터 포획할 수 있다. 상대 턴 중의 공격 판정도 이 지연을 읽는다.
추가 행동은 시간을 늘리지 않는다. 기한은 `rule_runtime.piece_fresh_until`에 보관하고 반복 키에는 상대 시간으로 정규화한다.
알리바바 추가 배치는 전체 안전 후보를 먼저 고른 뒤 체비쇼프 최소 거리와 칸 이름 순서로 후보를 확정한다.
가까운 칸이 위험하면 더 먼 안전한 칸을 사용하고, 안전한 칸이 없으면 추가 생성과 난수 소비를 생략한다.

현재 원본 프로필의 사신은 **상대의 포획으로 잃은 인접 아군 두 개**를 센다.
상대 기물의 죽음·희생·환경 제거·마법사 위험 지대는 영혼을 주지 않는다. 동시 처형 승리는 무승부로 처리한다.
마법사의 마나는 최대 5이며 번개/보호막/운석/시간 정지 비용은 1/2/3/5다.
운석은 클릭한 칸 기준 아래쪽 2×2이며 가장자리에서 보정한다. 상대의 완료 턴에 지연 효과를 처리한다.
시간 정지는 턴을 즉시 끝내지 않고 다음 상대 턴을 건너뛰게 한다.

무덤의 기억은 무덤이나 카드가 아직 없어도 갱신한다. 대형 룩·비숍의 기억은 일반 룩·비숍으로 정규화하고
콜로서스는 제외한다. 잡힌 풍차 모드, 트릭스터의 실제 행마와 기존 기억을 가진 무덤도 처리한다.
동시 제거와 포털 배치 포획의 후보는 기존 배치 기억 경로에서 추첨한다.
기억은 탐색 상태 복사와 반복 키에 포함한다. 이로 인한 기존 회귀 fingerprint 변경은
[카드 구현 안내](card-implementation.md)의 회귀 기준에 기록했다.

## 검증과 남은 대조 범위

`scripts/test-piece-card-ports.mjs`는 SHA를 확인한 번들의 순수 함수만 격리 실행하고
`tests/fixtures/current-piece-cards.json`과 비교한다. 앱 전체를 실행하거나 외부 서비스에 접근하지 않는다.

- 단일 대상 카드 14장의 952개 선택 사례: 종류·색상·편집 왕실 허용 여부.
- 그래플러·풍차의 14개 선택 순서·쌍·왕실 사례.
- 8종의 32개 원본 권위 행마 사례와 기본 복사 행마 320개 사례(79종·풍차 두 모드, 양 색상·장애물 유무).
- 알리바바 안전 배치, 사신의 포획 조건·임계값, 주문 비용과 운석 64칸의 범위.

Rust 테스트는 공개 Engine 전이로 변환과 ID·상태 보존, 턴 유지, 희생, 난수 소비,
포획 지연, 신행마, 무덤의 과거 포획·풍차 모드·트릭스터·체커 점프·드래곤 교환,
아이돌 앙코르와 마법사·사신의 턴 경계를 검사한다. 웹의 두 대상 선택 안내도 검사한다.
전체 검증 스크립트에 원본 대조를 포함했다.

지원은 이 계약과 검증한 실행 범위를 뜻한다. 원본 사이트 전체 동작 일치를 의미하지 않는다.
대형 기물의 칸별 파편화·포털, 모든 강제 변환과 왕관의 조합, 전체 카드 조합의 우선순위와
난수 예약 순서의 완전 대조는 남아 있다. 무덤은 기본 행마 기억을 확장했으며 복사 원본의
모든 고유 능력·부가 상태 전달을 통째로 복제하는 범위는 포함하지 않는다.
이 범위를 넓힐 때 카드별 구현과 `ported.json`, 원본 대조 사례를 함께 갱신한다.
