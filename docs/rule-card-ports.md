# 최신 RULE 19장 이식

2026-10-29 작업 기준. `augment_chess_20261017`에서 계약 변경으로 미지원이던 RULE 19장을
카드별 모듈에 연결했다. 이 작업의 커밋은 `21eeb6f`다. 이후 [기물 카드 18장](piece-card-ports.md)을 추가해
현재 지원 범위는 **235/275장**, 미지원은 **40장**이다.
미지원 사유는 계약 변경 34장, 신규 2장, 원본 비활성 4장이다.

## 근거와 구현 범위

보관한 `main-RjrZ5fFP.js`의 실행 함수와 순수 헬퍼를 기준으로 했다.
SHA-256은 `2e932da7b9391effbeab3593ea5fdf855041fe5a74f611dfdfde678eee46beb8`이다.
이는 10-28 수집 바이트이며 10-17 당시 바이트의 증명은 아니다.
카드별 원본 줄 범위는 [ported.json](../rulesets/augment_chess_20261017/cards/ported.json)에 있다.

배열 이름으로 별도의 Chess960 캐슬링 규칙을 추론해 추가하지 않았다.

## 카오스 기물 의존성

65종 추첨에 필요한 그래플러·회전문·돈 키호테·무덤·베롤리나 폰·킬러·신호기·전송탑·배리어를
기물 종류와 행마에 추가했다. 잡기 속박, 이웃 회전, 돈 키호테의 자동 이동과 풍차 경로,
포획 행마 기억, 베롤리나 앙파상·승진, 킬러 자동 왕실 포획, 신호기 예약 승리,
전송탑 이동과 배리어 왕실 보호를 연결했다. 편집 국면에서도 기본 행동을 사용할 수 있다.
이 기물들의 별도 획득 카드 8장도 후속 [기물 카드 이식](piece-card-ports.md)에서 지원했다.
이 문서의 RULE 19장 수량에는 별도 획득 카드를 넣지 않는다.

## 저장·탐색·화면

카드별 설치와 정산은 `engine/cards/<id>.rs`, RULE 공통 호출 순서와 예약은
`rule_support.rs`, 추가 기물의 공통 실행은 `chaos_pieces.rs`가 소유한다.
`GameState.rule_runtime`은 힙에 보관해 긴 추가 행동 탐색의 스택 크기를 유지한다.
상태 복사에 포함하며 지연을 상대 시간으로 정규화해 반복 키에 넣는다.
의미 없는 절대 시각 때문에 고속도로 같은 영구 룰의 반복 판정을 방해하지 않는다.
왕관 계수·붕괴 단계·가속 개시·겨울 예고/동결·신호기 예약·무덤 기억 등은 탐색 상태를 구분한다.
기존 카드의 리플레이 저장 표현을 바꾸지 않도록 `card_runtime.october`와 분리했다.

웹은 중립 공과 괴물, 지형과 붕괴 칸, 겨울 예고/동결·왕관 보유·잡기 속박·신호기 점화 상태를 표시한다.
새 기물의 편집 선택지와 설명도 포함한다. 일반 합법 행동과 상태에 묶인 행동 배치 양쪽으로 실행한다.

## 검증과 후속 대조 범위

`scripts/test-rule-ports.mjs`는 원본 앱을 실행하지 않고 SHA가 고정된 순수 함수만 격리 실행한다.
960개 배열, 12개 카오스 시드와 65종 가치/가중치, 트릭스터 후보, 분류와 전투 가치,
가속 시점·붕괴 링·왕관 계수 및 돈 키호테 경로를 fixture와 비교한다.
`engine/cards/tests/rule_ports.rs`는 공개 Engine 전이로 설치·중복 거부·실패 원자성,
턴 경계·추가 행동·포획·자동 행동·승패·반복 키를 검사한다.
기존 128장의 512개 고정 회귀 사례는 별도로 유지한다.

지원 표시는 위 계약의 실행 연결과 검증 범위다. 원본 사이트 전체 동작 일치를 뜻하지 않는다.
대형 기물은 기존 코어의 앵커·HP 추상화를 사용하며 원본의 칸별 파편화와 대형 포털 통과는 남아 있다.
RULE의 동시 제거와 포털의 두 포획은 무덤 기억을 배치에서 추첨한다. 기타 다중 포획 효과와의 결합,
모든 강제 변환·복원과 왕관의 결합, 복사 능력의 전체 상태 전달,
전체 카드 조합의 우선순위와 원본 RNG 예약 소비 순서에 대한 완전 대조도 후속 범위다.
검증 범위를 넓힐 때는 이 문서와 `ported.json`의 범위를 함께 갱신한다.
