# 관측과 실제 상태의 구분

삭제한 V5 실험에서 전환에 필요한 정보 접근 원칙만 추렸다. 이 문서는 로컬 설계 원칙이며
원본 사이트 전체의 관측 명세를 인증하지 않는다. 현재 웹/탐색은 full-state 진단 경로다.

## 플레이어가 사용할 수 있는 정보

| 정보 | 범위 |
|---|---|
| 일반 공개 기물·지형·공개 상태·턴/행동 예산·종료 결과 | 양측 공개 |
| 카드 보유·charge·사용 사실 | 기존 로컬 계약의 공개 범위를 카드별 확인 |
| 자신의 실제 기물 정체·비밀 대상·개인 기억 | 해당 플레이어만 |
| 드래프트 offer·선택 메뉴·실패한 자기 시도 | 해당 결정자만 |
| RNG 내부 상태·숨은 배치·상대 비밀 mark·정책의 내부 표본 | 관측 입력에서 제외 |

STEALTH 이동 좌표는 상대에게 공개하지 않는다. SPY/TROJAN_HORSE의 비밀 대상은 설정자에게만
제공한다. HALLUCINATION/CAMOUFLAGE_COLOR는 observer에게 표시되는 정체를 사용한다.
이름이나 내부 runtime 필드를 근거로 임의의 공개/비공개 규칙을 만들지 않는다.

## 이후 플레이어 정책을 붙일 때

1. 후보 생성·정렬·탐색 예산과 정책은 플레이어의 관측과 기억만 사용한다.
   숨은 truth-legal mask로 후보를 가지치기하지 않는다.
2. 실제 legality는 referee 엔진이 판정한다. 허용된 시도의 실패와 엔진 오류를 구분한다.
3. 같은 관측/기억을 만드는 실제 배치를 바꿔도 후보·정책 입력이 변하지 않는지 검사한다.
4. 실제 상태를 읽는 전술 진단은 별도 적용 전제를 검증한 영역에서만 사용한다.
   full-state 교사의 답을 그대로 불완전정보 학생의 정답으로 저장하지 않는다.
5. 환경 chance와 상대 행동의 확률을 구분한다. 고정 seed 하나를 exact posterior나
   모든 확률 결과에 대한 증명으로 취급하지 않는다.
6. actor와 완료 턴을 구분한다. 중간 선택과 같은 턴의 연속 행동도 실제로 탐색한다.

카드별 관측 projection·기억·posterior·복구 구현은 새 플레이어 경로가 필요할 때 구현하고 검증한다.
